<h3 class="text-xl font-bold text-white mb-2">Use Case: Batch II Continuity</h3>
<p class="text-gray-300 leading-relaxed">
This is the second shipment of the same sub-assembly commission, so the whole point was consistency: every component — wings, riders, lances, jetbike chassis — painted in the same stages as the first batch, then handed off for final assembly. The palette stays locked so the full squad reads as one force rather than two separate jobs.

Tactical Protocol
</h4>
<span class="text-[10px] uppercase text-gray-500">Methodology</span>
</div>
<p class="text-sm text-gray-400 mb-2">Key techniques deployed:</p>
<ul class="space-y-2 text-sm text-gray-300 list-disc list-inside marker:text-cyan-500">
<li><strong>Cross-Batch Recipe Match:</strong> Base coats, washes, and highlights measured against the first batch to avoid drift in gold tone or red saturation.</li>
<li><strong>Sub-Assembly Reach:</strong> Undersides of the wings and rider interiors painted before mounting, so no brushwork was skipped in the seams.</li>
<li><strong>Metallic Separation:</strong> Warm gold and cool silver kept apart with dedicated washes, preserving each surface's identity.</li>
</ul>
