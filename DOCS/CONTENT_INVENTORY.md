## 1 · 现状诊断（实测，不是判断）

### 1.1 四套等级词汇打架

| 出现位置 | 体系 | 档数 |
|---|---|---|
| 首页委托条（`i18n/*.toml`） | 桌游级 / 展示级 | 2 |
| 报价页（`content/rates/index.zh.md`） | 战场标准 / 阅兵标准 / 殿堂典藏 | 3 |
| `i18n` 里另一套残留 | 标准 / 精英 / 大师 | 3 |
| 55 篇作品的 `tier:` 字段 | Battleline / Specialist / Spec Ops / Master / Legend | 5 |

客户在首页看到「展示级」，点进报价页找不到这个词；看作品页标着 `Spec Ops`，三处都对不上。

### 1.2 两种货币，数字对不上

- 首页：`¥120 起 / 件`、`¥600 起 / 件`
- 报价页模板 `layouts/_default/services.html:130` 硬编码 `$`，渲染成 `$5` / `$15` / `$45 起`
- $5 ≈ ¥36，与首页 ¥120 差 3.3 倍

### 1.3 四个页面是暗的

`content/rates` `content/process` `content/about` `content/contact` 全部带 `noindex: true` + `sitemap.disable: true`；首页顶栏只链「作品」和「涂师」。

**结果**：搜索引擎收不到你的报价页和流程页，访客从首页也点不进去。`hugo.toml` 的 `menu.main` 里配了这几项，但首页模板没用 `menu.main`，是写死的两个链接。

### 1.4 对标站普遍有、你没有的内容块

94 站里 26 个涂装工作室的标准骨架是：
`首页 · 服务/等级 · 图库 · 流程 · 定价 · 关于 · FAQ · 联系/报价`

你缺的是：**可筛选图库**、**FAQ**、**客户评价**、**组装/底座/附加服务价目**、**付款与排期条款**。

### D5 · 交付版 / 发布版怎么分

**背景**：作品页的第一功能是给客户做交付确认（几百张图没法单独发，所以做成灯箱）。流程是「初期交付版（未上地台）→ 客户确认 → 上地台 → 发布版」。但 56 篇 frontmatter 里**没有任何字段区分这两种状态**，导致：

- 首页 hero 自动取最新一篇 → 展示的必然是刚交付、未完成的那一版
- 作品集把两种状态混在一条时间流里，访客分不出哪些是完成品
- 搜索引擎收录的是半成品

**已定（2026-09-02）**：**不做 `stage` 字段系统。**

理由：交付版只存在 2-3 天，客户确认后原地址、原图直接替换成发布版。为一个 2-3 天的窗口建一套状态机制不划算，缓冲期内不美观可以接受。

- 发布版覆盖原页面，URL 不变 ✅ 已定
- 不加交付版标记、不做单独 noindex ✅ 已定
- **唯一要处理的副作用**：首页 hero 现在自动取「最新一篇」，所以每次交付后的 2-3 天，首页主图必然是未上地台的那一版。解决办法不需要状态字段，改成**钦定一件**即可（见 D6）。

### D6 · 首页主图由谁决定
