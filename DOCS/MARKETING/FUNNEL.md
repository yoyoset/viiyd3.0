# 获客漏斗全景图 (Acquisition Funnel)

> 用途:看清"从潜在客户看到内容,到付定金开工"这条链路上,**每一段现在是通还是断**。用 ✅ 有 / ⚠️ 半成品 / ❌ 缺 标注当前状态,缺什么写在对应段落。全图只有一条主线:内容 → 作品页 → 表单 → Telegram → 报价 → 定金。

```
 内容/入口        承接(落地页)           转化(委托流程)          交付与复购
┌──────────┐   ┌──────────────┐   ┌────────────────────┐   ┌────────────────┐
│ IG        │→ │ /work/ 作品页 │→ │ 委托表单(Worker)    │→ │ 开工/进度/交付   │
│ 公众号     │→ │ /rates/ 报价  │→ │ Telegram 通知+跟进   │→ │ 客户返图/转介绍   │
│ 小红书(X)  │→ │ /process/ 流程 │→ │ 报价→定金50%→开工   │→ │ 老客户回流        │
│ SEO 搜索   │→ │ /contact/ 表单 │→ │ (LEAD_SOP.md 细化)  │   │ (缺机制)          │
│ 转介绍/老客 │   └──────────────┘   └────────────────────┘   └────────────────┘
└──────────┘
```

## 四、复购 / 转介绍(老客户回流)

| 机制 | 状态 | 现状 | 缺什么 |
|------|------|------|--------|
| 老客户回流 | ❌ | 无 | 交付时做三件事(零成本):①交付话术里加一句"下次可以直接来,不用再走表单";②交付后 2 周问一句"上桌了吗?方便的话想看看返图";③返图发社媒时征得同意 + @ 客户 |

## 五、漏斗现状一句话总结

```
入口:IG 未知活跃度,SEO 在自动累积,小红书/X/公众号未确认,转介绍=0
承接:页面全通 ✅(50 作品页 + rates + process + contact)
转化:表单 ✅ → Telegram 通知 ✅ → 跟进/报价 ⚠️(有工具无话术)→ 定金/进度/交付 ⚠️(有规定无具体操作)
复购:❌ 无机制
```

**当前最明显的断点**:入口层(内容没人发 → 没有流量进来),其次是转化层(有自动化通知,但"收到 Telegram 之后做什么"没有成文)。前者由 CONTENT_IDEA_BANK.md + CALENDAR.md 解决,后者由 LEAD_SOP.md 解决。
