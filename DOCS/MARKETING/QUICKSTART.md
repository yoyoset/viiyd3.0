# 一句话执行手册 (Quickstart)

> 给"完全不懂营销的丈夫 + 只负责画画的妻子"各一页。**不用想,照着做。** 全文就一句话逻辑:**囤货日把内容做好 → 每周固定两天照抄发布 → 收到委托按 LEAD_SOP 回。**

---

## 给丈夫的一页(发布 + 跟进,每周约 60 分钟)

### 每周固定动作(≈45 分钟)

- [ ] **周二 20:00 发 IG**(5 分钟):打开囤货清单 → 复制文案 → 贴图(清单里指定的 URL/编号)→ 发布 → 回一下评论区
- [ ] **周五 20:00 发 IG**(5 分钟):同上,发清单里周五那条
- [ ] **回复评论/私信**(10 分钟):私信统一回"谢谢!更多作品在 viiyd.com,想委托可以直接填网站表单(我把链接发你)"——别在私信里谈价
- [ ] **看一眼钉住的 Telegram 工单**(10 分钟):有新委托就按 LEAD_SOP 第一步分类;A 类当晚报价,B 类当晚发追问,钉住消息保持 ≤3 条
- [ ] **素材收集**(10 分钟):把妻子本周的语音/返图抄进素材本(微信收藏即可),月底囤货日用

### 每月固定动作(≈2 小时)

- [ ] **第 1 个周末:囤货日**(2 小时):按 CALENDAR.md 第四节批量做下月 8~10 条内容 + 1 篇公众号,排好期
- [ ] **第 1 个周日 20:00:公众号发长文**(10 分钟,囤货日已写好)
- [ ] **月底最后周末:复盘**(20 分钟):按 METRICS.md 第三节模板填 6 个数
- [ ] **顺带**:查一次 D1 线索数(`wrangler d1 execute` 命令在 METRICS.md)

### 交给 AI agent 做的(你不必自己写)

- 从妻子的语音/笔记生成 IG 中英文案(喂它 CONTENT_IDEA_BANK 模板)
- 按囤货清单把图 URL、文案、标签排进日历
- 从当周 IG 拼公众号长文初稿
- 查"旧作品还能挖什么角度"(把作品页链接丢给它)

### 必须人做的(别交给 AI)

- **发布动作本身**(复制粘贴+点发布,AI 替你发不了)
- **妻子的话的最终润色**(把 AI 腔删掉——发布前通读一遍,像 AI 写的就删)
- **报价和收款**(AI 可以起草话术,但价格、定金、收款必须你经手)
- **客户隐私判断**(返图能不能发、客户故事能不能讲,必须问过客户)

---

## 给妻子的一页(画画 + 提供素材,每周 <10 分钟)

> 你不需要懂任何营销。你的任务只有三个:**画画、拍图、说一句话。**

### 每周固定动作(<5 分钟)

- [ ] **画画间隙,给丈夫发一句语音**(30 秒):今天在想什么、卡在哪、某个细节怎么调。一句话就行,别写小作文——文案的事丈夫和 AI 会干
- [ ] **有客户返图/聊天截图,转给丈夫**(10 秒)

### 每月一次(10 分钟,囤货日)

- [ ] 丈夫挑好下月的 8~10 张图后,你对每张**说三个词**:"这是谁/当时想什么/哪里最喜欢"——这就是文案的种子

### 交作品时(每次,约 10 分钟)

- [ ] **拍全**:正面/侧面/细节特写/地台/氛围图,交给丈夫走发布流水线(`.agent/workflows/publishing.md`)——这批图同时用于:发客户确认、上作品页、进社媒内容池
- [ ] **有条件就做 360° 视频**(转台一圈,15~30 秒,深色背景)——这是最强素材

### 你不用管的事(全权交给丈夫 + AI)

- 文案、选图、标签、发布、回复评论、报价话术、复盘——**都不是你的活**
- 你的判断只在一个地方生效:客户问"能不能做成 XX 效果"时,由你拍板"能做/不能做/要加钱",因为只有你知道工时

## 一句话兜底

**每周稳定 2 条 IG + 每月 1 篇公众号 + 收到委托 24h 内回** = 这套体系的全部。内容没了就从 CONTENT_IDEA_BANK 的兜底清单挖旧作品,别停下来想"该发什么"——**先发,再想。**
