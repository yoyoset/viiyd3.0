# 渠道内容流水线 (Channel Playbooks)

> 用途:每个渠道一份"照做就行"的发布 SOP。频率与 CALENDAR.md 严格一致;所有渠道的选图、文案都从同一份囤货清单出,**不做任何渠道独有创作**(除小红书标题外)。
> 渠道现状:Instagram = 在用(有账号,活跃度待确认);公众号 = 策略既定平台(账号待确认);小红书、X = 建议新增(按"开号+养号"最小路径给方案,**不要假设已存在**)。

---

## 渠道一:Instagram(主力,在用)

**状态:⚠️ 账号存在(`@viiyang.yingying`,登记于 `about/index.md`),实际活跃度/粉丝无数据。**

### 发布 SOP

| 项 | 规定 |
|----|------|
| 内容类型 | 作品展示 / 360° 视频(轮播或 Reel)/ 细节特写 / 教程 / 日常(见 CONTENT_IDEA_BANK 第二节) |
| 发布频率 | **周二 + 周五 20:00(北京时间)**,各 1 条;周日 Story 可选(CALENDAR.md 第一节) |
| 图片选图规则 | 5 图轮播:① 整件/氛围主图(cover)→ ② 面部或亮点特写 → ③ 一处细节 → ④ 地台/环境 → ⑤ 全景收尾。单图帖只挑"放大也耐看"的一张(细节/特写优先)。图从 work 页 plates(`_NN` 编号)选,已标注顺序的见各 `social_media.md`(Bullgryns/Kasrkin) |
| 文案模板 | CONTENT_IDEA_BANK 第 1/2/4/9 类;第一人称、"画的过程 > 结果"、留一处真实不足。**发布前丈夫通读一遍,凡是像 AI 的话删掉**(对照 SOCIAL_MEDIA_STRATEGY.md 的禁词表) |
| CTA | 作品页链接(bio 或图文直链):"Full gallery on the site / 高清单图在网站"。**bio 必须常年带 viiyd.com** |
| 标签策略 | 核心 8~12 个:内容池每条标注了标签(social_media.md 示例含 `#warhammer40k #minipainting #commission #osl #gloweffects` 等);每帖换 2~3 个具体标签(作品名如 `#silentking #necrons`),避免每帖同一套 |
| 驱动字段 | `content/work/[slug]/index.md` 的 `cover`/`photos:`(选图)、`video_360`(发视频)、`paints:`(教程/配色)、`social_media.md`(现成文案) |

### 每月 5 分钟维护

- 回所有评论(哪怕只回一个表情);私信 24h 内回(见 LEAD_SOP 的响应承诺)。
- 每季度把最强的 1~2 个作品设为置顶 Highlights(分类:WORK / 360° / BTS)。

## 渠道二:公众号(主线,账号待确认)

**状态:⚠️ 是 SOCIAL_MEDIA_STRATEGY.md 的既定平台(长文格式已定),但账号是否存在未确认。**

### 发布 SOP

| 项 | 规定 |
|----|------|
| 内容类型 | 长文(作品深度记录/配色技术解析),一条长文 = 当周 2~3 条 IG 内容的"拼盘升级版" |
| 发布频率 | **每月第 1 个周日 20:00 固定 1 篇**;第 3 个周日"有素材才发"(CALENDAR.md 第一节) |
| 图片选图规则 | 文章开头 1 张整件主图 → 正文随段落插入细节图(图片用 `_web` 缩略版或原图都行)→ 结尾 1 张全景 + 公众号内嵌 360° 视频(有条件) |
| 文案模板 | 结构固定:灵感/为什么接 → 颜色 → 技术 → 一句真实感受 → CTA。示例长文草稿已存在:`content/work/2026-01-23-bullgryns-.../social_media.md` 的"WeChat Official Account"小节,直接复制改 |
| CTA | 文末固定:"点击阅读原文查看高清大图"→ 链到作品页;再加一句"展示位每季度只开两个"的稀缺提示 |
| 标签策略 | 公众号无标签;靠**标题关键词**(含 战锤/涂装/模型/作品名)吃微信搜一搜 |
| 驱动字段 | 同 IG:`cover`/`photos:`/`video_360`/`social_media.md` |

### 开号最小路径(若账号不存在)

1. 微信公众平台注册"订阅号"(个人即可,免费,无需对公账户)。
2. 名称建议直接含关键词:"VIIYD 战锤微缩涂装工作室"(微信搜一搜会匹配名称)。
3. 首篇发 **Bullgryns 长文**(草稿现成),并把它设为**自动回复的欢迎语**(新人关注自动收到作品集入口)。
4. 每次发完 IG 作品帖,把同一素材攒着,月底拼一篇长文——公众号不是额外创作,是 IG 的月末汇总。

## 渠道三:小红书(建议新增,勿当主力)

**状态:❌ 无账号,无维护。定位:国内获客的"搜索引擎",养号 1 个月后再谈转化。**

### 开号 + 养号最小路径

1. **开号**:个人号即可,名称"VIIYD 战锤涂装",简介带网站 `viiyd.com` + "涂装委托"关键词(小红书禁止直接放微信,放网站链接合规)。
2. **置顶 3 篇**:最强作品(静默王 360° 视频 / Miao Ying 龙鳞 / Bullgryns)+ 1 篇"工作室在做什么"自我介绍。
3. **养号节奏(第 1 个月)**:每周 2 篇,**完全复用 IG 囤货清单**(改封面 + 标题口语化 + 封面大字)。平台给新号 30 天流量扶持,这个月只看互动量,不看转化。
4. **标签策略**:封面必须有标题大字(小红书是"封面即标题"),文案标签 5~8 个:`#战锤 #微缩模型 #模型涂装 #代涂 #涂装工作室 #成都 #手办涂装 #游戏模型`。
5. **转化路径**:私信 → 引导填网站表单(把 `/contact/` 链接发过去)→ 走 LEAD_SOP。小红书私信有敏感词限制,别在站内谈价。

> **为什么只建议每周 2 篇、不设第 3 个主力**:两个人没有余力维护第三个"要自己创作内容"的渠道。小红书只吃 IG 剩饭,一个月总投入约 30 分钟。

## 渠道四:X(Twitter,建议新增,维护成本最低)

**状态:❌ 无账号。定位:海外社区存在感,吃 IG 剩余流量。**

### 开号 + 发布 SOP

1. **开号**:名称 `@viiyd_studio` 类,简介 + 置顶一条"Commissions open, portfolio: viiyd.com"。
2. **频率**:每周 2~3 条,**直接复用 IG 周二/周五帖**(英文文案压到 1~3 句 + 图 + 链接),`publishing.md` 已有 X 模板([HOOK] → 1~2 句 → [链接] → hashtags)。
3. **标签**:3~5 个:`#Warhammer40k #minipainting #commission #WIP`;可参加 `#MiniMonday` 社区话题(每周一旧图再发一次,零成本)。
4. **CTA**:链接作品页;bio 常驻网站。

> 小红书和 X 是"锦上添花":**主线永远是 IG + 公众号 + 线索跟进**。第 1 季度不要同时开两个新号,先开小红书(国内获客价值大于 X),X 等小红书稳定了再开。

## 全渠道复用关系(一次囤货,N 处分发)

```
囤货日一次产出:
  IG 周二/周五帖(图 + 中英文案)
      ├─→ 小红书:改封面 + 口语化标题(国内)
      ├─→ X:英文压成短帖(海外)
      └─→ 公众号:每月攒 4~8 条 IG 帖 → 拼 1 篇长文(深度版)
```

**唯一的渠道独有工作**:
- 小红书:封面大字 + 标题(20 分钟/批)
- 公众号:把多条 IG 拼成长文的组织(30 分钟/篇,已有草稿可抄)
- X:压短文案(10 分钟/批)

**不存在的渠道独有工作**:选图、成文、拍摄——全部共享一份素材与文案。
